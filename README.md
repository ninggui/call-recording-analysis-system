## 解决什么问题

手机里躺着几千条通话录音，想复盘但不知道从哪下手：

- 一条一条转写？手动要几个月
- 按人找对话？根本搜不动
- AI 给个摘要就完了？想要人物画像、风险识别、自我复盘

这套系统把"海量录音"自动变成"可检索的知识库"，8000+ 条实测跑通。

## 流水线

```
录音文件
  │
  ▼ ① 上传到飞书云空间
  ▼ ② 盘点文件
  ▼ ③ 批量创建妙记转写（并发5，1.5-4s随机间隔）
  ▼ ④ 导出转写文本
  ▼ ⑤-⑧ 按联系人分组合并文档
  ▼ 上传飞书
  ▼ 深度分析第一层：画像/风格/风险/复盘
  ▼ 深度分析第二层：完整对话互动模式
  ▼
飞书云文档 + 多维表格索引
```

## 五层分析

| 层 | 输出 | 状态 |
|----|------|------|
| ① 数据层 | 批量转写、按人归档、多维表格索引 | ✅ |
| ② 人物画像 | 通话频率/时长/活跃时段、高频词、沟通风格、if-then行为模式 | ✅ |
| ③ 意图与风险 | 潜台词识别、前后一致性检测（欺瞒识别）、风险三级评估 | ✅ |
| ④ 自我复盘 | 表达风格分析、沟通缺陷识别、成长追踪、场景化策略库 | ✅ |
| ⑤ 知识沉淀 | 人物关系图谱、事件时间线、经验教训库、沟通模板库 | 🔄 |

## 实测参数

这些是 8000+ 条实测出来的稳定值，别改：

| 参数 | 推荐值 | 踩过的坑 |
|------|--------|---------|
| 并发数 | **5** | 10 立即限流 |
| 请求间隔 | 1.5-4s 随机 | 固定间隔会被识别 |
| 批次大小 | 50 个 | 再大会超时 |
| 批次休息 | 30s | 不休息必限流 |
| 连续失败退避 | 5 分钟 | 立刻重试只会更糟 |
| 处理速度 | 900-1200 条/小时 | — |

## 避坑清单（血泪教训）

1. **飞书 files list 有 1500 条隐性上限**——升序降序都只返回同样 1500 个。解法：处理完的文件移到别的文件夹，循环直到源文件夹清空
2. **>100KB 文档上传必超时**——先建空文档，再分段追加
3. **单块子节点超限**（degrade_code=4000021）——大文档分段追加，别一次塞
4. **token 10-15 分钟失效**（99991668）——定时任务监控自动重启
5. **不能只靠 files list 查重**——更新前必须 `drive +search` 按名称搜
6. **说话人保留 Speaker 1/2/3 原样**——无法确认主叫，别乱标

## 每个联系人的文档长什么样

```
1. 深度分析（最前面）
   - 基础画像 / 沟通风格 / 意图与风险 / 自我复盘 / 摘要时间线
2. 目录
3. 高频关键词
4. 通话 1/N - 时间
   - AI 摘要、关键词、待办、完整对话
```

## 使用边界

- 来自个人真实业务场景，参数为实测值，不同账号需微调
- 不含个人数据（真实联系人/号码/通话内容已脱敏）
- 依赖飞书企业版，个人版可能不可用
- 务必遵守限流参数，否则账号可能被封
